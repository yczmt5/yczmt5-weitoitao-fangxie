# 罗列式·公共套话黑名单（累积增长，只做字符串比对）

**用途**：罗列式稿子写完，拿本清单**逐句比对**（grep，不读全文）。命中的句子一律换掉，**开头位和结尾位命中即返工**。

**为什么单列一份**：这类句子既不是原文独有，也不是新稿独创，是**全网通用句**——所以"让子代理不见原文"防不住它，子代理凭自己的语料照样写得出来。查重系统对这类句子的命中率最高，尤其**开头第一句和结尾最后两句**（金句位、措辞高度固定）。只能靠事后比对清掉。

**例外不适用**：开头位、结尾位的公共套话，**不适用"原文高频使用可保留"的例外**。原文自己用了，新文更不能再用——那等于和原文正面撞上。

**增长规则**：每次用户说"太像原文／相似度高"，定位到的新命中句子，**原样追加到对应位置**（只加句子，不写分析）。下次比对时就会拦下它。

## 四、判别通用问法（黑名单没收录时用这一问兜底）

把**开头第一句、结尾最后两句、每条解释句**单独拎出来，逐句问：

> **这类文章里，是不是人人都会写这么一句？**

是 → 就是公共套话，必须换成一个**具体的、带个人语气的说法**：谁、什么时候、当时什么反应、后来怎么想。开头保留"现状感叹 + 条数承诺"的功能，但不能用公共感叹；结尾保留"总结两句、陈述收尾"的形态，但不能用公共金句。
