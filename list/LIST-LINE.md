# 罗列式线 · 入口（list/）

本文件夹是**罗列式线**，覆盖：**清单推荐型／误区纠偏型／习惯方法型／对比判断型**。

判为**罗列式观点文**，才进本文件夹。**判为故事叙事型／生活观察型／连续论述型的，去 `story/`，本文件夹本次不读、不检、不记。**

---

## 1. 本线要读的文件

- **`form-list.md`** —— 本线全部规则，自带硬闸门。**不必从头读到尾**，读这几处即可：**第 3 节**（开头句式骨架照搬、核心名词不许移位、数量承诺）、**6.1**（排版逐篇重判）、**7.0**（条目分类与事由置换）、**7.0.1**（套话禁写、句式错位、动作错位）、**7.1 第 2 步**（观点质量六条，含硬度守恒）、**第 8 节**（雷 A／雷 B）、**第 9 节**（判定七条）、**15.1**（字数区间）。
- **`list-cliche-blacklist.md`** —— 公共套话黑名单。**由机检自动读取并检查**（开头位／结尾位命中即 FAIL），**主对话不读、不 grep**。
- **`prescription-fixed.md`** —— 本线**处方固定段**（通用硬约束＋额外纪律＋交稿指令，每篇一字不变）。**主对话不读，只在处方末尾写一行指针**：`通用硬约束、额外纪律：照抄 list/prescription-fixed.md 全文`，**子代理自己打开读全文**。不含任何原文内容，隔离不受影响。

## 2. 本线专属记录

- **`_local/case-log.md`** —— 本线的经验记录（**相似度线**）。**只在用户明确说"这次通过了／相似度过了，记录下"时**追加一条，固定三行（关键几手／差点翻车／待固化）。**不记骨架、不记事由清单**——那两样由当篇原文决定，下篇用不上。
  同一类坑够 3 次 → 升级成黑名单条目或 `form-list.md` 里的一行条款 → **从本文件删掉**。

## 3. 本线硬边界（三条，不许越）

1. **本线只解决相似度，不做朱雀处理。** 不读、不检、不记 `story/` 的任何文件，不搬人工特征条款。
2. **观点可以和原文重合，每条底下装的具体事由必须逐条换掉。** 相似度在**事由层 + 论述层**解决——不许用"换观点"来降相似度。
3. **降相似度不许越过"案例现实成立"这条红线。** 事由要常识兜得住、这个岁数的人真干得出来；不许跳到需要专门知识才能判断真假的领域。
4. **语言层要大白话顺读。** 句子卡人的地方，几乎都长在**必须自编、手边又没有现成话可借**的位置（开头、收尾、每条的判断句）——在那里被现场造词，就成了拗口。**禁的是这类文章的公共金句，不禁家常话、老话、街坊真会说的说法**，这两条别搞混，一混就会全篇自己造词。**字数不够靠补话、不靠压句**——在句子内部删虚词、缩搭配，正是拗口的头号来源。纪律全文在 `prescription-fixed.md` 的额外纪律里，子代理必读。

## 4. 本线执行顺序（不许加环节）

`判文体 → 本文件 → form-list.md（必读各处）→ 出处方（固定段写一行指针，指向 prescription-fixed.md）→ 交子代理（子代理自读固定段、自写正文、自跑机检到 PASS）→ 主对话机检一次复核 → 交稿`

机检：`python scripts/sim_check.py <原文> <新稿> --banned "词1,词2,..."`，出 PASS 才交稿。

**主对话的动作清单（就这几下，多一下都是浪费）**：① 调技能；② 并行打开本文件与 `form-list.md` 必读各处；③ 原文落盘 ＋ 同一条命令里跑完字数统计；④ 出处方 ＋ 交子代理；⑤ 复核一次机检；⑥ 交稿（**正文贴进对话，不落 md 成品文件**）。
**判据：一篇跑完，主对话往返 ≤7 次、子代理内部 ≤5 次；每篇跑完自报这两个数。**（耗时＝趟数 × 每趟时长——优化先看趟数，再看每趟。）

**三条硬禁令（与 `story/` 同一口径）**：

1. **正文归子代理写。** 主对话不许自己动笔写正文，也不许替它改稿——**观点与事由是主对话的活，论述与成文是子代理的活**（`form-list.md` 第 7 节切分铁律）。主对话亲自落笔，等于把子代理那一轮作废，而且用的是最重的上下文去干最费的活。
2. **机检出 PASS 即交稿。** 主对话只看报告最后一行结论；**不许一处一改**（一处就是一轮），要改一次改完；**不许为了改而先打开成品文件**（子代理汇报里已贴全文）。
3. **4—5 字重合一律不管。** 硬线只有一条：**连续 6 字以上完全重合＝0**。收紧四五字短串不降相似度，只白耗往返。
